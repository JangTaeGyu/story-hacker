# 001 - 원본 대비 차이 맞추기 (폐기)

> **이 문서의 지침은 더 이상 따르지 마세요.**
> 작성 시점의 목표는 원본 프로토타입(`reference/StoryHackerWithIllust.jsx`)의
> 사이버펑크 UI와 화면을 일치시키는 것이었습니다. 이후 **NOCTURNE 리디자인**으로
> 팔레트·타이포·문구가 전부 바뀌면서 전제가 사라졌습니다.

*원본 작성일: 2025-01-20 / 폐기 표시: 2026-08*

---

## 왜 폐기되었나

이 문서는 아래와 같은 변경을 지시하고 있었습니다. 지금 적용하면 오히려 현재 디자인을 깨뜨립니다.

| 지시했던 내용 | 현재 |
|---|---|
| 완료 화면 아이콘을 🏆 + `animate-bounce`로 | 이모지를 쓰지 않음. 골드 그라데이션 디바이더 + 명조 타이틀 "사건 해결" |
| 완료 타이틀을 `EPISODE CLEAR!`로 | "사건 해결" / `Case Closed` |
| 게임오버 타이틀을 `ACCESS DENIED`로 | "수사 실패" / `Access Denied` |
| 게임오버 아이콘을 🔒로 | 이모지 없음 |
| 추리 모드에 시안 글로우 배경 추가 | 단일 골드 팔레트. 모드별 색 구분을 없앰 |
| `text-gray-500`, `bg-hacker-dark` 등 | `noct-*` 토큰으로 전면 교체 |

체크되어 있던 "미세 조정" 항목들은 실제로 한 번 적용되었다가 리디자인 과정에서 되돌려졌습니다. 체크 표시를 근거로 현재 상태를 판단하지 마세요.
