# Story Hacker

추리와 논리로 비밀번호를 해독하는 퍼즐 게임

## 게임 모드

### 스토리 모드
스토리 속 단서를 읽고 PIN 코드를 추리합니다. 힌트를 사용할 수 있지만 별점이 감소합니다.

### 추론 모드
주어진 상황과 단서로 PIN 코드를 추론합니다. 틀릴 때마다 새로운 단서가 공개됩니다.

## 기술 스택

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS

## 시작하기

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev
```

http://localhost:3000 에서 게임을 플레이할 수 있습니다.

## 스크립트

```bash
npm run dev     # 개발 서버
npm run build   # 프로덕션 빌드
npm run start   # 프로덕션 서버
npm run lint    # ESLint 실행
```
